# Blinkit Power BI Dashboard

This project analyzes Blinkit product data to uncover insights into sales, profit margins, stock ranges, and shelf life trends — offering a snapshot of quick commerce performance.

## 📊 Dashboard Pages
1. **Overview Page:**  
   - KPIs: Total Sales, Profit Margin, Average Shelf Life  
   - Category-wise visuals: Sales Value, Profit Margin %, Price Range  
   - Product movement analysis by shelf life (Fast / Medium / Slow)

2. **Stock Insights Page:**  
   - Comparison of Min, Max, and Range of Stock Levels by Category  
   - Top brands by stock range variation  
   - Key highlights of stock efficiency

## 🧠 Key Takeaways
- Avg. Profit Margin: ~40%  
- Avg. Shelf Life: ~232 days  
- Top Categories: Pet Care, Instant Food, Snacks & Munchies  

## 🛠️ Tools Used
- Microsoft Power BI  
- DAX  
- Data Cleaning and Modeling
